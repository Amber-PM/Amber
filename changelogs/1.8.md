# 1.8.0

#### Fixes

- Entities already flagged for despawn, such as a picked up item, are no longer saved with their chunk, which closes a small item duplication window.
- Shulker boxes can no longer be put inside other shulker boxes through inventory transactions.
- Smithing recipes that return one of their own ingredients, like the netherite upgrade and armor trims, are no longer rejected. Items created out of nothing are still refused.
- Every furnace recipe now gets its own recipe network id in the crafting data.
- Book page replacing and swapping is limited to 50 pages.
- Removing Slowness no longer breaks from level 7 on. Levels above 6 count as level 6 for the speed change.

#### Performance & Stability

- Sounds and particles are routed without reflection and without looking up viewers again, making `addSound` about 4 times faster with many players.
- Broadcasts share one type converter lookup per protocol instead of validating it for every recipient.
- Protocols listed in `network.allowed-protocols` are preloaded at startup, which slows the boot a little but removes the pause of about 0.3 seconds on the first login of each protocol. Nothing changes while the list is empty, the default.
- New option `level-settings.leveldb-block-cache-mb` sets the LevelDB block cache of each world, in MB. The default `0` keeps the LevelDB default of 8 MB, so nothing changes unless you raise it.

#### Requirements

- PHP 8.4 or newer is now required: [Get Latest Binaries](https://github.com/Amber-PM/PHP-Binaries/releases).
