# Major 1.4.0
#### Primitive Shapes:
- Native PrimitiveShapes API added to core.
- 10 shape classes: `LineShape`, `BoxShape`, `SphereShape`, `CircleShape`, `TextShape`, `ArrowShape`, `CylinderShape`, `PyramidShape`, `EllipsoidShape`, `ConeShape`.
- `ShapeRegistry` global ID counter. `ShapeHandle` with `.remove()` and `.update()`.
- `World::addShape()` broadcasts to viewers and tracks shapes per chunk.
- Chunk shape replay: players loading a chunk receive all active shapes in it.
- `World::addTemporaryShape(pos, shape, durationTicks)` — client auto-removes when time runs out, server cleans up `$activeShapes` via `ClosureTask`.
- `World::addShapeGroup(shapeDefs)` — batch add, returns `ShapeGroup`.
- `ShapeGroup` — groups multiple handles under one token: `remove()`, `update(index, shape)`, `count()`.
- `Entity::attachShape(shape, offset)` — shape follows the entity client-side via `attachedToEntityId`. Auto-removed on entity close.
- `Entity::detachShapes()` — removes all shapes attached to the entity.
- `Player::addShape()`, `removeShape()`, `clearShapes()` — player-private shapes.
- `NetworkSession::sendShapes()`, `removeShapes()` — batched send.
- `WorldShapeEvent` — cancellable, same pattern as `WorldParticleEvent`.
- All 10 shape classes accept `$rotation: ?Vector3` (yaw/pitch/roll) as last optional parameter.

#### PrimitiveShapes Example:
```php
// world shape
$handle = $world->addShape($pos, new BoxShape($pos, new Vector3(2, 2, 2), color: new Color(255, 100, 0)));
$handle->update(new BoxShape($pos, new Vector3(3, 3, 3)));
$handle->remove();

// temporary shapes removed after 5s
$world->addTemporaryShape($pos, new SphereShape($pos, 20, 2.0), durationTicks: 100);

// arena with one token
$arena = $world->addShapeGroup([
    [$pos->add(-10, 0, 0), new CylinderShape(...)],
    [$pos->add( 10, 0, 0), new CylinderShape(...)],
    [$pos->add(0, 4, 0),   new TextShape($pos->add(0, 4, 0), "§ePVP ARENA")],
]);
$arena->update(2, new TextShape($pos->add(0, 4, 0), "§aRound 2!"));
$arena->remove();

// entity attach
$entity->attachShape(new CircleShape($pos, 32, 1.2, new Color(255, 215, 0)), offset: new Vector3(0, 2.5, 0));

// 3d rotation
$world->addShape($pos, new BoxShape($pos, new Vector3(2, 2, 2), rotation: new Vector3(45, 0, 0)));

// player private
$handle = $player->addShape(new TextShape($pos, "§aOnly you can see this"));
$player->clearShapes();
```

#### ClientInputLocksAPI
- `InputLockFlags` enum — typed bitmask flags: `MOVEMENT`, `ROTATION`, `JUMP`, `SNEAK`, `MOUNT`, `DISMOUNT`, `HOTBAR`, `ATTACK`. `InputLockFlags::all()` returns full mask.
- `Player::lockInputs(InputLockFlags ...$flags)` — disables the given inputs natively on the Bedrock client via `UpdateClientInputLocksPacket`. No rubberband, no event cancel loop.
- `Player::unlockInputs(InputLockFlags ...$flags)` — re-enables specific inputs without touching others.
- `Player::clearInputLocks()` — removes all active locks in one packet.
- `Player::hasInputLock(InputLockFlags $flag)` — query whether a specific lock is active.
- `Player::getInputLocks() : int` — returns the raw bitmask of active locks.
- `PlayerInputLockEvent` — cancellable event fired on every lock/unlock call. Handlers can modify the resulting flag mask.
- Active locks are reset to `0` on disconnect (`onPostDisconnect`).
- Supported on all clients >= 1.20.80 (all accepted protocols in this build).

#### ClientInputLocksAPI Example:
```php
$player->lockInputs(InputLockFlags::MOVEMENT, InputLockFlags::JUMP);

if($player->hasInputLock(InputLockFlags::MOVEMENT)){
    $player->unlockInputs(InputLockFlags::MOVEMENT);
}

$player->clearInputLocks();
```
