# 1.4.0
#### Including in this release:
- Implemented native PrimitiveShapes API directly into PocketMine-MV core.
- Added 10 concrete shape classes (`LineShape`, `BoxShape`, `SphereShape`, `CircleShape`, `TextShape`, `ArrowShape`, `CylinderShape`, `PyramidShape`, `EllipsoidShape`, `ConeShape`).
- Added process-wide `ShapeRegistry` ID counter and `ShapeHandle` lifecycle token with idempotent `.remove()` and real-time `$handle->update()` support.
- Added `addShape()` and `getChunkShapes()` methods to `World` with viewer broadcasting and chunk shape tracking.
- Added automatic chunk shape replay: clients loading chunks automatically receive all active primitive shapes in that chunk.
- Added player-scoped shape management (`addShape()`, `removeShape()`, `clearShapes()`) to `Player`.
- Added batched network shape dispatch (`sendShapes()`, `removeShapes()`) to `NetworkSession`.
- Added cancellable `WorldShapeEvent` for shape creation interception.

#### Quick Usage Example:
```php
use pocketmine\color\Color;
use pocketmine\math\Vector3;
use pocketmine\world\shape\shapes\BoxShape;
use pocketmine\world\shape\shapes\TextShape;

// Spawn a shape in the world for all viewers
$handle = $world->addShape($pos, new TextShape($pos, "§eProgress: §a0%"));

// Update the shape in real-time without flickering
$handle->update(new TextShape($pos, "§eProgress: §a50%"));

// Remove the shape when done
$handle->remove();
```
