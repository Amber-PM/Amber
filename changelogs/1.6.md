# 1.6.0
#### Native Camera API
- Added `Player::getCamera()` for presets, camera instructions, fades, shakes, FOV, targeting, and entity attachment.
- Added a protocol-aware camera preset registry and builder for custom presets.

#### General Fixes / QoL
- Added built-in `/world` command with `load`, `unload`, `tp`, and `list` subcommands.
- Added built-in `/protocols` command to view accepted protocols, client versions, and online player counts per protocol.
- Added `education.enabled` to `pocketmine.yml` to optionally hide built-in Education items from creative inventory.
- Added `TextFormat` constants for Bedrock material colors (`MATERIAL_*`) and party blue (`PARTY_BLUE`).
- Included `BedrockData` assets for protocol 2193 (block network IDs, canonical states, meta maps, and jigsaw structures).
- Added protocol admission validation in `Server` and `SessionStartPacketHandler`.
- Fixed client placement prediction in adventure mode by sending `can_place_on` and `can_destroy` in `ItemStackExtraData`.
- Fixed missed swing detection across consecutive ticks in `PlayerAuthInput`.
- Played attack feedback sounds for hits blocked by hurt cooldown in adventure mode.
