# 1.6.0
#### Native Camera API
- Added `Player::getCamera()` for presets, camera instructions, fades, shakes, FOV, targeting, and entity attachment.
- Added a protocol-aware camera preset registry and builder for custom presets.

#### Native Gameplay Mechanics
- Added a native redstone engine with signal propagation, scheduled updates, hoppers, and note blocks.
- Added pistons and sticky pistons with a 12-block push limit, slime/honey adhesion, entity displacement, and movable container data.
- Added dispensers and droppers with redstone-triggered item dispensing, projectile behaviors, bucket/TNT/armor actions, and container transfers.
- Added native shield blocking, projectile deflection, durability, axe disable cooldowns, and banner decoration.
- Added crossbow charging and firing with Quick Charge, Multishot, arrows, and firework rockets.
- Added Elytra gliding with durability, fall-damage handling, and firework boosts.
- Added native tipped arrows and potion-effect projectiles.
- Added tameable wolves and cats with following, sitting, collars, breeding, and persistent ownership.
- Added native Armor Stands with equipment, poses, interaction events, and persisted state.
- Added native Bedrock Spectator mode with movement and interaction restrictions.

#### Forms API
- Added fluent `MenuForm`, `ConfirmForm`, and `CustomForm` builders with typed responses and callbacks.
- Added protocol-aware form serialization, legacy element fallbacks, close reasons, and stricter input validation.

#### World Backups
- Added manual world backups through `/world backup` and configurable automatic LevelDB backups with asynchronous verification and retention.

#### General Fixes / QoL
- Added built-in `/world` command with `load`, `unload`, `tp`, `list`, and `backup` subcommands.
- Added built-in `/protocols` command to view accepted protocols, client versions, and online player counts per protocol.
- Added `education.enabled` to `pocketmine.yml` to optionally hide built-in Education items from creative inventory.
- Added `TextFormat` constants for Bedrock material colors (`MATERIAL_*`) and party blue (`PARTY_BLUE`).
- Included `BedrockData` assets for protocol 2193 (block network IDs, canonical states, meta maps, and jigsaw structures).
- Added protocol admission validation in `Server` and `SessionStartPacketHandler`.
- Fixed client placement prediction in adventure mode by sending `can_place_on` and `can_destroy` in `ItemStackExtraData`.
- Fixed missed swing detection across consecutive ticks in `PlayerAuthInput`.
- Played attack feedback sounds for hits blocked by hurt cooldown in adventure mode.
- Fixed firework explosion metadata so crossbow rockets with stars display explosion particles, while starless rockets do not.
- Fixed Education item textures on 26.x clients by restoring the built-in chemistry resource pack stack.
- Fixed dropping items with signed block hashes using the drop key on 26.50+ clients.
- Fixed iron doors and trapdoors opening by hand while preserving redstone activation.
- Fixed tipped arrows losing their potion effects when fired from dispensers.
- Fixed untamed cats receiving their collar color as a body tint.
- Fixed armor stand placement rotation to face the player in 45-degree steps.
- Fixed shield-blocked melee hits to knock back the attacker without triggering regular hit sounds or melee enchantment effects.
- Prevented healing, regeneration, and tipped-arrow potion effects from reviving entities after lethal damage.
- Fixed firework rocket collision behavior, flight metadata, Multishot consistency, damage attribution, and duplicate explosion handling.
- Improved per-protocol chunk caching, block/item palette sharing, and older-client fallback mappings.
- Fixed offhand action validation to avoid unintended hotbar changes and orphaned inventory predictions.
- Fixed anvil item duplication, replayed login attempts, and oversized item rename inputs.
