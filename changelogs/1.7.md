# 1.7.0
#### NetherNet
- Added the NetherNet (WebRTC) transport on top of the native `ext-rtc` extension. Clients from 26.50 on join over NetherNet and 26.60 clients only use NetherNet, while RakNet keeps serving older versions.
- Added signed answers with a persistent `nethernet.key` server identity, and the transport key is checked against the Login key.
- Added per-IP limits for signaling and connections, plus rate-limited console hints for closed ports, failed authentication and `max-per-ip`.
- Added native ping and bandwidth stats for NetherNet sessions, shown in `/status`.
- Added `network.nethernet.ice-port-range`, `ice-udp-mux` and `advertised-address`, plus the `AMBER_NETHERNET_PORT` and `AMBER_NETHERNET_PUBLIC_IP` environment variables for panels and containers.
- The console now prints the TCP and UDP ports to open on startup.

#### Multi-Version
- Added Minecraft: Bedrock Edition 26.60 (protocol 2225) alongside the earlier supported versions.
- Included `BedrockData` assets for protocol 2225.

#### Hosting
- Added `network.raknet-port` to move RakNet to another UDP port or turn it off with `-1` on single-port hosts.
- `/etc/machine-id` is only read when it is readable, so locked-down containers no longer crash on startup.
- The phar cache falls back to a `tmp` folder next to the phar when `/tmp` is too small, as on most hosting panels.

#### Gameplay & Worlds
- Added a data-driven Bedrock JSON loot table engine for entity drops.
- Added the `modern` overworld generator with 1.18+ multi-noise terrain, 3D caves, aquifers and the deepslate stratum.
- Added vehicles: boats, chest boats, minecarts with powered and activator rails, plus 1-block crawling.
